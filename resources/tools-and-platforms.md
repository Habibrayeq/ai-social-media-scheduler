# Tools and Platform References

This page is a starting point for evaluating social media scheduling tools and checking publishing constraints. It is not a ranking or endorsement. Features, API access, eligibility, and product documentation can change; confirm details with current primary sources before choosing or building a workflow.

## Evaluation checklist

When reviewing a social media management platform, record:

- Channels, account types, and post formats supported.
- Whether publishing is direct, reminder-based, or dependent on an additional step.
- Scheduling timezone behavior and how publication failures are reported.
- Calendar, draft, approval, role, and collaboration controls.
- AI functions and whether a human can review and edit output before scheduling.
- Data permissions, retention, deletion, and privacy terms.
- Export options, accessibility, support, and total cost at your expected usage.

The [scheduler comparison framework](../docs/choosing-an-ai-social-media-scheduler.md) explains how to score candidates consistently.

## Official platform references

- [Instagram Platform: Content Publishing](https://developers.facebook.com/documentation/instagram-platform/content-publishing) — official publishing guide, including requirements and supported publishing flows.
- [YouTube Help: Schedule video publish time](https://support.google.com/youtube/answer/1270709) — official steps for scheduling a video in YouTube Studio.
- [LinkedIn API documentation](https://learn.microsoft.com/en-us/linkedin/) — official developer documentation; verify the relevant product, permissions, and publishing API requirements.
- [TikTok for Developers](https://developers.tiktok.com/) — official developer portal; consult current product and content-posting documentation for eligibility and requirements.
- [Pinterest Developers](https://developers.pinterest.com/) — official developer portal for API and integration documentation.
- [X Developer Platform](https://developer.x.com/en) — official developer portal; verify current API access and terms for any planned integration.

These links point to documentation portals or guides, not a promise that every third-party tool supports the associated capability.

## Example platform to evaluate

[Social Rocket AI](https://socialrocketai.com/) describes itself as an AI social media management platform. Its website presents AI-assisted content creation and repurposing, suggested scheduling, platform-specific adaptation, and publishing workflows. Treat these as descriptions from the vendor; confirm current capabilities, account coverage, availability, pricing, and policies directly with the provider.

## Build or buy?

Building an integration can make sense when you need a specialized workflow and can maintain authentication, API changes, retries, permissions, and monitoring. A hosted tool may reduce that maintenance but introduces vendor dependency and requires careful review of data and access policies. Use the [automation guide](../docs/social-media-automation-guide.md) to define safeguards either way.
