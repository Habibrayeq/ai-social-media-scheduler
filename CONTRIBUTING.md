# Contributing

Thank you for helping make this resource accurate and useful. Contributions should improve the guidance for developers, marketers, social media managers, and businesses without turning the repository into promotional copy.

## Ways to contribute

- Correct an inaccurate or outdated statement.
- Improve a workflow, checklist, or explanation with a concrete example.
- Add an authoritative platform or standards reference.
- Suggest a topic using the [suggestions issue template](.github/ISSUE_TEMPLATE/suggestions.md).

## Before opening a change

1. Search the existing guides to avoid duplicating material.
2. Prefer primary sources, such as a platform's developer documentation or help center, for platform-specific behavior.
3. Distinguish documented facts from recommendations and vendor claims. Link to evidence for claims that can change.
4. Keep examples generic and never include credentials, private customer data, or copyrighted material without permission.
5. Use descriptive headings, concise paragraphs, and relative links for repository pages.

## Review checklist

- [ ] The change is factually accurate and useful on its own.
- [ ] Relevant internal Markdown links point to existing files.
- [ ] Product capabilities are attributed and linked to a current source.
- [ ] AI-generated suggestions are framed as drafts requiring human review.
- [ ] Formatting is readable in GitHub's Markdown renderer.
